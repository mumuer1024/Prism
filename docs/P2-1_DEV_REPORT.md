### 4. 模板详情

#### 情报日报模板

**科技情报日报**
- 聚焦科技领域动态
- 包含：今日热点、技术趋势、产品发布、学术前沿、社交热议、深度洞察
- 标签：科技、日报、技术趋势、AI

**商业情报日报**
- 聚焦商业和投资领域
- 包含：资本动向、市场机会、创业动态、商业洞察、竞品追踪
- 标签：商业、投资、创业、市场分析

**开发者日报**
- 聚焦开发者领域
- 包含：热门开源、技术文章、工具推荐、学习资源、坑点避雷、社区讨论
- 标签：开发者、开源、技术、工具

#### V2EX 赏金模板

**技术外包机会扫描**
- 筛选技术外包需求
- 关键词：外包、开发、预算、报价、项目
- 评分标准：预算明确度、需求清晰度、时间紧迫度

**设计兼职机会扫描**
- 筛选设计类兼职
- 关键词：设计、UI、UX、Logo、海报
- 类型：UI设计、Logo设计、品牌设计、插画

#### Chrome 扩展模板

**效率工具机会扫描**
- 扫描生产力工具类别
- 筛选条件：用户量>=1000，评分<=4.2
- 机会评估：重写竞品、快速复制、UI优化

**开发者工具机会扫描**
- 扫描开发者工具类别
- 筛选条件：用户量>=500，评分<=4.3
- 机会评估：刚需付费、快速迭代、技术壁垒

#### Alpha 雷达模板

**Web3 项目雷达**
- 搜索 Web3/区块链开源项目
- 聚焦：Solana生态、DeFi协议、NFT项目、加密工具
- 输出：项目名称、描述、GitHub、Token状态、潜力分析

**AI 项目雷达**
- 搜索 AI/机器学习开源项目
- 聚焦：LLM工具、AI代理、计算机视觉、NLP
- 输出：项目名称、描述、GitHub、Stars、商业化潜力

#### 营收分析模板

**SaaS 商业机会分析**
- 挖掘 SaaS 产品机会
- 分析维度：SaaS机会、目标用户、定价建议、MVP建议、风险提示
- 输出：可执行的 SaaS 产品建议

**个人品牌机会分析**
- 挖掘个人品牌建设机会
- 分析维度：内容选题、涨粉机会、变现路径、背书机会、行动计划
- 输出：个人品牌建设路线图
